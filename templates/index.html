Analytical Graph Topology Case Studies Solutions

Case Study 1: AI Service Architecture

Architecture: A–B, B–C, B–E, C–D, C–E, D–E, D–F, E–F.
Components: A (Image Upload), B (Preprocessing), C (Object Detection), D (Tracking), E (Database), F (Dashboard).

  • Degrees: deg(A)=1, deg(B)=3, deg(C)=3, deg(D)=3, deg(E)=4, deg(F)=2.
  • Direct Connections: E (Database) connects directly with B, C, D, and F.
  • Max Degree: E has the highest number of direct connections (degree 4).
  • Failure Impact: If link C–E is disabled, only C and E are affected directly (deg(C) drops to 2, deg(E) to 3).

Case Study 2: Data Centers Network

Vertices: V = {1, 2, 3, 4, 5}
Edges: E = {(1,2), (1,3), (2,3), (2,4), (3,5), (4,5)}

  • Cut-Set Matrix: Graph has no single bridge cut-edge (edge connectivity λ=2). All minimal cuts are size ≥ 2.
  • Critical Links: No single link failure disconnects any center. Minimal cuts isolating individual nodes are of size 2 (e.g. {(1,2),(1,3)} for node 1; {(2,4),(4,5)} for node 4; {(3,5),(4,5)} for node 5).
  • Proposed Links: Add link (1, 4) or (1, 5) to eliminate 2-edge bottlenecks and provide direct multi-path redundancy.
